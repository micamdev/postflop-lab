# Postflop Lab 1.0.0

The first release of Postflop Lab, a free and open-source GTO postflop solver for Windows
and Linux. It continues [Desktop Postflop](https://github.com/b-inary/desktop-postflop)
by Wataru Inariba, whose development stopped in October 2023. It adds what Desktop Postflop
had on its roadmap: saving results, node locking and aggregated reports over many flops.

## Highlights

- **New interface:**
  - Library, Setup and Results views.
  - Strategy, Equity, Breakdown and Compare views of every node.
  - Per-card Turn and River tables.
- **Library:**
  - Solutions are saved as `.plab` files in `Documents\Postflop Lab\Solutions`.
  - Three save depths: complete; up to the turn, with rivers re-solved when you pick them; flop only.
  - Import, export, rename and search by name or board.
- **Node locking:** lock a strategy at any node, then re-solve the tree around it.
- **Flop subsets and aggregated reports:**
  - Solve a representative subset of the 1755 flops (25 to 1755 flops) in one batch.
  - Read the c-bet frequencies and sizes, equity, EV, EQR and nut advantage, weighted over all flops.
  - Filter by texture, view as a chart, export to CSV.
- **Setup:**
  - Saved ranges and trees, with drag and drop.
  - Tree line editing.
  - Memory estimate before solving.
  - 16-bit precision for large trees.
- **Reliability:** an internal error is reported instead of closing the app, and a refused load leaves the open solution as it was.

## Coming from Desktop Postflop

- **Separate installation:** Postflop Lab installs next to Desktop Postflop rather than replacing it. Uninstall Desktop Postflop yourself if you no longer need it.
- **Settings not carried over:** configurations and display preferences saved in Desktop Postflop do not appear in Postflop Lab, because it uses its own data folder. Enter your ranges again and save them in the range explorer.

## Downloads

- **Windows:** `.msi` installer, or the standalone `postflop-lab.exe` (it needs the WebView2
  runtime, present on Windows 11 and most Windows 10 machines; the installer adds it if missing).
- **Linux:** `.deb` package or `.AppImage`.

macOS is not built yet.
