# Postflop Lab 1.3.0

**Big blinds everywhere, ready-made trees, and an app that runs on any PC.** If you run 1.1.x
or 1.2.0, this version installs from inside the app: click **Update to 1.3.0** in the top bar.

## New

- **Amounts in big blinds:** the pot, the stack and the rake cap are typed in bb (5.5, 97.5,
  6), and every amount reads in bb: actions (`Bet 1.8 · 33%`), pots and stacks in the tree,
  EVs in the grid, the table, the charts, the flop reports and the CSV exports, the
  exploitability (`0.026bb (0.47%)`). Saved ranges, trees, spots and solutions open as before.
- **Default trees:** a **Default** folder in the Trees tab with six trees whose bet sizes we
  measured with the solver: single raised pot (opener in position) and 3-bet pots (3-bettor
  out of position or in position), each in a normal and a simplified version. They are
  ordinary trees: load, edit, rename or delete them. A new Setup starts with the simplified
  single raised pot and the NL50 rake (5%, capped at 6bb).
- **Keyboard:** the explorer (Ranges, Trees, Spots) works with the arrows, Enter and Space;
  the save dialog keeps the keyboard inside, and Escape closes it.

## Fixed

- **Older or budget processors:** the app no longer closes at start on a processor without
  AVX2 (some Pentium / Celeron laptops, older PCs, virtual machines). Processors with AVX2
  keep the same speed.
- **Solve keeps your solution when memory is short:** the memory is checked before the open
  solution is replaced, so a refused solve no longer loses an unsaved solution. A tree too
  large for the memory is refused with a message instead of closing the app.
- **Many node locks:** a solution with many node locks can now be saved (it failed from about
  ten locks, blaming the tree configuration).
- **Large libraries:** the library list no longer freezes the window after a big batch.
- **Linux:** without a Documents folder set up, the library goes to `~/Documents`.
- **One window:** opening the app again shows the open window instead of a second copy.
- **Saving on Windows:** a save is no longer lost when an antivirus or OneDrive holds the new
  file for a moment.

Note: a solution saved with very many node locks (over about ten) cannot be opened by 1.2.0
or older.

## Downloads

- **Windows:** `.msi` installer, or the standalone `postflop-lab.exe`. Only the `.msi`
  updates from inside the app.
- **Linux:** `.AppImage`, which updates from inside the app, or the `.deb` package.
