# Postflop Lab 1.1.0

## New

- **In-app updates.** Postflop Lab now checks for a new version when it starts. When one
  is out, an **Update** button appears in the top bar. Click it to download, install and
  restart, after a confirmation if the current solution is not saved. Updates are signed:
  the app only installs packages built for Postflop Lab.
- **Bet sizes in % of the pot.** Actions show their size next to the amount, for
  example **Bet 18 · 33%** or **Raise 73 · 60%**. You see this in the results navigation,
  the strategy cards, the node lock editor, the tree editor and the flop report. Raises
  follow the usual convention: the increase over the pot after calling.
- **A ready-to-solve Setup.** A new Setup is now a real spot:
  - a 100bb single raised pot (pot 55, stack 975, in tenths of a big blind);
  - bet sizes already filled in: 33% and 75% on the flop, 75% on the turn and river,
    raises 60%.

  Add ranges and a board to solve. **Clear** still empties everything.

## Changed

- **Solve target.** The default target is now 0.5% of the pot (it was 0.3%). It is the
  usual study precision and solves faster. Settings you already changed are kept.
- **Flop subsets have their own target:** 0.5%, 1% (the default) or 2% of the pot. A
  report averages many flops, so each one needs less precision.

## Website

## Updating from 1.0.0

1.0.0 cannot update itself. Install 1.1.0 once with the `.msi` below. It replaces 1.0.0
and keeps your saved solutions. From then on, new versions install from inside the app.

- **Windows:** in-app updates use the `.msi` installer. If you run the standalone `.exe`,
  download new versions from this page instead.
- **Linux:** the `.AppImage` updates itself. The `.deb` package does not: install new
  versions from this page.

## Downloads

- **Windows:** `.msi` installer, or the standalone `postflop-lab.exe`. The standalone
  `.exe` needs the WebView2 runtime, which is present on Windows 11 and most Windows 10
  machines; the installer adds it if missing.
- **Linux:** `.AppImage` or `.deb` package.
