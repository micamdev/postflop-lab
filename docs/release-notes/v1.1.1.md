# Postflop Lab 1.1.1

Fixes and small improvements. If you run 1.1.0, this version installs from inside the app:
click **Update to 1.1.1** in the top bar.

## Fixed

- **Tree lines editor:** leaving it with unsaved changes now asks first (Save, Discard
  or Stay). Before, going back to the Setup or loading a solution dropped the edit
  without a word.
- **Library:** two saves under the same name at the same moment (for example a batch
  saving while you save or rename) can no longer silently replace one another.
  Renaming or deleting during a long save no longer freezes the window.
- **Memory estimate:** the Setup's Memory panel now counts the bunching effect's tables,
  as Solve does, so it no longer says a solve fits when it does not.
- **Stopping a paused solve** with an invalid thread count no longer ends in an error.
- **Lock re-solve:** after "Save first", it checks again that nothing else started.

## Improved

- **Flop report chart:** negative EV now shows below a zero line instead of
  disappearing.
- **Keyboard:**
  - In the flop report, sort by a column with the keyboard and open a flop with Enter.
  - The batch dialog closes with Escape.
- **Threads** can be changed while a solve is paused.
- **A range being edited** keeps its edit mode and Cancel when you open the tree lines or
  the bunching view.
- **Bet sizes in % of the pot** also show in Compare's strategy bar and in the turn and
  river chart legend.
- **A board's cards** show as text when you hover them ("Kd 8s 3c").

## Downloads

- **Windows:** `.msi` installer, or the standalone `postflop-lab.exe`. Only the `.msi`
  updates from inside the app.
- **Linux:** `.AppImage`, which updates from inside the app, or the `.deb` package.
